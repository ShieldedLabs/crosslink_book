# Overview

Shielded Labs' Crosslink is an in-development complete protocol design covering consensus, networking, usability, and security considerations intended for the [Zcash](https://z.cash/) network. In addition Shielded Labs is developing software for a prototypical fully verifying node and also finalizer and wallet support.

This book is focused on the design itself, rather than software implementations.

There are multiple opportunities to get involved: design contributions, joining our live Feature Net, and more. See [The Shielded Labs' Crosslink Site](https://shieldedlabs.net/crosslink/) to get involved!

## Status

The Shielded Labs' Crosslink project is in a "productionization" phase, during which we are refining and analyzing the design and software to make it "production ready" as a stand-alone Zcash consensus feature.

This phase and it's conclusion of "production readiness" does not imply this protocol change will be accepted or deployed in Zcash!

For this design book, this includes making the specification more precise, documenting design choice rationales, alternatives considered, and analysis results.

For further information, see the current [Shielded Labs' Crosslink Roadmap](https://shieldedlabs.net/roadmap/).
